# Libcararian Web

楽譜PDFを結合して小冊子（B4見開き・中綴じ）にしたり、曲ごと・ページごとのPDFに分けたりするWebアプリです。
PDFはブラウザの中だけで処理し、外部には送りません。デスクトップ版 Libcararian（Python）をWebに移したもので、印刷結果は現行版と同じです。

## 動かし方

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # 型チェック・リント・単体テスト
npm run test:e2e   # 画面操作テスト（インストール済みの Chrome を使う）
npm run compat     # 現行版（Python）の出力と画像で比べる。Python と pymupdf・numpy が必要
npm run build      # dist/ に静的サイトを出力
```

## 使い方

1. 「PDFを追加」を押すか、画面にPDFをドロップします。全ページがファイルごとに並びます。
2. 番号（01, 02…）をドラッグしてファイルを並べ替えます。「名前順」でも並べ替えられます。
3. ページの間にマウスを合わせると「＋」が出ます。押すと、その位置に白紙が入ります。
   - 横長のページは、ページの下の「回転」を押すと、右に90°ずつ回ります。
   - ファイル全体は「全ページ回転」で回せます。
4. 右の設定パネルで、出力方法（結合・小冊子／曲ごと／ページごと）を選んで設定します。
5. 「確認」を押すと、出力結果が表示されます。中身を確かめてから「ダウンロード」を押します。
   - 結合・小冊子は PDF でダウンロードします。
   - 曲ごと・ページごとは ZIP でダウンロードします。

## データの保存場所

保存はしません。追加したPDFと設定はブラウザのメモリにだけ置き、ページを再読み込みすると消えます。

## 既知の制限

- ページ単位の削除と並べ替えは、まだできません。
- 小冊子では、各ページを横方向だけ縮めます。現行版と同じ動作です。
- 数百ページの出力には十数秒かかります。目安は、300ページで約10秒です。
- パスワードで保護されたPDFは読み込めません。
