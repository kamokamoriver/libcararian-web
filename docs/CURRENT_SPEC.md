## 寸法と単位

| 項目 | 値 |
|---|---|
| B5（縦） | 515.9 × 728.5 pt |
| B4（横、見開き） | 1031.8 × 728.5 pt |
| mm から pt への換算 | mm × 2.83 |
| ページ番号の書式 | Helvetica 12pt（reportlab の初期値） |

## ファイル管理

- 複数のPDFを追加できる。同じパスのファイルは二重に入らない。
- ドラッグで並べ替える。「名前順」はファイル名で並べ、大文字と小文字を区別しない。
- ✕ で1件ずつ外す。「クリア」は確認してから全部外す。
- この並び順が処理の順番になる。

## プレビュー

- 入力ファイルを1ページずつ表示し、前後のページへ送れる。
- ページ数・ファイル名・タイトルを表示する。
- 出力結果のプレビューはない。

## B5への変換（全機能で共通）

1. `/Rotate` が指定されたページは、中身を実際に回転させ、`/Rotate` を0にする。
2. 縦横を別々の比率で拡大・縮小し、B5に合わせる。そのため、縦横比がB5と違う元ページは伸び縮みする。

## 一括結合

1. 全ページを並び順につなげ、すべてB5に変換する。
2. 小冊子ありの場合:
   - 4の倍数になるまで末尾に白紙を足す。
   - 並びは中綴じ順。総ページ数を n とすると、i = 0, 2, 4, … について (n−1−i, i) と (i+1, n−2−i) の順で並べる。
   - 各ページは、横方向だけを `(B4の幅 − 余白pt) / 2 / B5の幅` 倍に縮める。縦は縮めない。
   - 左のページは x=0、右のページは x = B4の幅 − 縮めた後の幅 に置く。
   - ページ番号は、左のページなら (15, 10)、右のページなら (B4の幅 − 27, 10) が描き始めの位置。
3. 小冊子なしの場合: ページ番号は全ページ (486.9, 10) に描く。この値は reportlab の B5 の幅 498.9pt（ISO B5 = 176mm）から 12 を引いたもの。実際の出力ページの幅は 515.9pt なので、番号の右には約29ptの余白が残る。
4. 番号の値は `ページの位置(0始まり) + 開始番号 − 表紙のページ数`。位置が表紙のページ数より前のページには付けない。
5. 初期値: 余白 20mm、開始番号 1、表紙 0。ファイル名が空欄なら「結合ファイル」。

## 曲ごと分割

- 全ページをB5に変換して結合したうえで、曲ごとに取り出す。
- ページの位置は `印刷されているページ番号 − 冒頭ページ番号`。
- ファイル名は `{種別}{No.を2桁}{曲名}.pdf`。種別は「-」(空)・混声・女声・男声から選ぶ。
- 入力が不完全な行は黙って飛ばす（曲名が空、数値でない、開始 ≤ 0、終了 < 開始）。No. が空なら1になる。
- ページ範囲からはみ出したページは黙って捨てる。

## ページごと分割

- 全ページをB5に変換し、`{接頭辞}{3桁の連番}.pdf` で1ページずつ保存する。
- 接頭辞が空欄なら連番だけになる。
- 読み込めないファイルは飛ばす。保存先に同じ名前のファイルがあれば上書きする。
- 旧版の別アプリ（PyQt5）は、B5に変換せず、接頭辞が空欄なら `page_` を付ける。

## 不具合と弱点

1. 完了メッセージの `\\n` が改行にならず、そのまま表示される。
2. ~~番号が端で切れる~~ → 誤りだった。描き始めの位置は、右端から約29pt（小冊子なし）、約27pt（小冊子の右ページ）。Helvetica 12pt の3桁は幅約20ptなので収まる。
3. 小冊子にするために足した白紙にも番号が付く。
4. ページ枠の原点が (0,0) でないPDFは、配置がずれる。
5. 数値欄に数字以外を入れても知らせず、初期値で処理する。
6. 種別の欄は自由に入力できるが、候補以外の値は空として扱われる。
7. 曲名にファイル名として使えない文字があっても確認しない。
8. プログレスバーは開始時と終了時の2段階しか動かない。
9. 一時フォルダとZIPを作る関数があるが、どちらも使っていない。
